# CodeAlpha Emotion Recognition from Speech

## Project Overview
This project identifies emotions from speech audio using Machine Learning.

## Objective
To classify emotions such as happy, sad, angry, and neutral from audio recordings.

## Technologies Used
- Python
- Google Colab
- Librosa
- NumPy
- Scikit-learn

## Feature Extraction
MFCC (Mel-Frequency Cepstral Coefficients)

## Machine Learning Algorithm
Random Forest Classifier

## Dataset
RAVDESS Speech Emotion Dataset.

## Workflow
1. Load speech recordings.
2. Extract MFCC features.
3. Assign emotion labels.
4. Train the Machine Learning model.
5. Evaluate the model using accuracy and a classification report.
